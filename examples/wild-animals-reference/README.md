# Wild Animals reference pack

This self-contained **REFERENCE / EXAMPLE** pack proves the C1 `game-cards-world`
format against the C2 validator. It derives four cards, comparison values,
localized copy, and source structure from the existing canonical Wild Animals
world, while using tiny original SVG reference illustrations instead of copying
production photo binaries.

It is deliberately not imported by the app, not a catalogue item, and not a
claim that production Wild Animals has been migrated to community-pack format.
Run it from the OH Play app directory:

```bash
npm run validate:community-pack -- examples/community-pack-reference-wild-animals
```
